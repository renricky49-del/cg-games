# cg-games

Three HTML5 games built for release on CrazyGames. English UI.

| Folder | Game | Based on (genre reference) | Branch |
|---|---|---|---|
| `zombie-night-shelter/` | Zombie Night Shelter: idle tower defense, defend your apartment through the night | idle "hide & defend dorm" TD | `game/zombie-night-shelter` |
| `letter-legion/` | Letter Legion: random-summon merge TD where units are letters and heroes are summoned by spelling words | random summon + merge TD | `game/letter-legion` |
| `mahjong-push/` | Mahjong Push: slide-and-match mahjong tile puzzle with a teahouse renovation meta | push-to-align pair matching | `game/mahjong-push` |

Shared requirements for every game: see `docs/CRAZYGAMES_REQUIREMENTS.md`.
Each game folder is a self-contained build: zip the folder contents (index.html at root) and upload to the CrazyGames developer portal.
